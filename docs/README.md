# Development docs

Progressive entry point for agents and developers.

| Need | Read |
|---|---|
| Start any feature or bug fix | [Workflow](workflow.md) |
| Change code or add tests | [Code and tests](code-and-tests.md) |
| Work with PSMF history, cache, or statistics | [Match data](match-data.md) |
| Deploy or validate in browser | [Deployment and E2E](deployment-e2e.md) |

Read only the row matching the task, then follow its validation path. Never put secrets or user credentials in docs, logs, commits, screenshots, or chat.
